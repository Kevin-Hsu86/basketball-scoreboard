# 籃球電子計分板

一個用瀏覽器就能使用的籃球計分板，手機、平板、電腦都能開。

## 線上使用

直接打開：[籃球電子計分板](https://kevin-hsu86.github.io/basketball-scoreboard/)

## 功能

- 主客兩隊計分（+1、+2、+3，可扣 1 分更正）
- 比賽計時與進攻時間（24 秒），兩者同步開始與暫停
- 可自訂每節分鐘數與進攻時間秒數
- 節次切換，換節自動重設犯規與計時
- 團隊犯規（達 5 次以紅字提醒）與暫停次數
- 球權切換、復原上一步
- 時間到提示音，可開關
- 鍵盤快捷鍵，空白鍵開始或暫停
- 資料自動保存在本機瀏覽器
