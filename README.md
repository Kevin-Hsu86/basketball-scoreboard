# 籃球電子計分板

一個專業的網頁計分板，用瀏覽器打開就能記錄籃球比賽。

## 線上使用

直接打開：[籃球電子計分板](https://kevin-hsu86.github.io/basketball-scoreboard/)

## 功能

- 主客兩隊分開計分（+1、+2、+3，可扣 1 分更正）
- 犯規次數紀錄，達 5 次以紅字提醒
- 倒數計時器：開始、暫停、繼續、重設
- 可自訂隊名與每節時間
- 一鍵全部歸零
- 加上提示音、進攻時間同步、暫停次數、球權、復原等功能
